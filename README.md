# DRESSO — тема WordPress

Самостоятельная блочная тема WordPress для магазина [DRESSO.eu](https://dresso.eu/) на WooCommerce. Основана на Clothes Boutique 0.3.1. Идентификатор темы и text domain — `dresso`. Устанавливать исходную Clothes Boutique не требуется.

**Версия:** 1.0.4  
**Лицензия:** GPLv3 или более поздняя. Сведения об исходном проекте и сторонних компонентах: [NOTICE.md](NOTICE.md).

## Сборка ZIP

Все необходимые файлы, включая шрифты и иконки, уже находятся в Git. Оригинальный архив Clothes Boutique не нужен.

В WSL:

```bash
cd /var/www/dresso-theme
git pull --ff-only
sudo apt install -y zip unzip

bash scripts/build-theme.sh dresso-install.zip
unzip -tq dresso-install.zip
sudo cp dresso-install.zip /var/www/dresso-install.zip
```

Результат: `/var/www/dresso-install.zip`. Внутри архива находится каталог `dresso/`.

Скрипт собирает архив **только из файлов последнего коммита (`HEAD`)** и проверяет контрольные суммы шрифтов. Незакоммиченные изменения в ZIP не попадают.

## Установка и обновление

1. Сделать резервную копию базы данных и установленной темы WordPress.
2. Открыть **Внешний вид → Темы → Добавить новую → Загрузить тему**.
3. Загрузить `dresso-install.zip`. Если тема DRESSO уже установлена, подтвердить замену существующей версии.
4. Проверить главную страницу, меню, категории, карточки товаров, корзину, оформление заказа и мобильное отображение.

**Важно:** изменения, сохранённые через WordPress Site Editor, могут храниться в базе данных как `wp_template`, `wp_template_part` и `wp_global_styles`. Они могут иметь приоритет над файлами темы, поэтому обновление ZIP не всегда меняет соответствующий шаблон на сайте.

## Экспорт изменений из WordPress

Экспортировать тему из редактора WordPress, распаковать ZIP в **отдельный временный каталог** и сравнить файлы с репозиторием. Переносить только нужные изменения, проверять `git diff` перед коммитом. Не заменять весь репозиторий содержимым экспорта: в нём могут отсутствовать файлы сборки и другие исходники.

Автоматический деплой на сайт не настроен.
